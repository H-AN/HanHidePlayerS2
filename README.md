
隐藏附近队友, 三种模式, 输入!hide 打开菜单, Sqlite数据库支持.

```
支持Sqlite数据库保存玩家设置, 进入服务器 后根据SteamId自动创建玩家表 并填入默认配置

1. 全局隐藏, 开启后隐藏所有队友 无视距离
2.按右键隐藏, 开启后 按1下右键隐藏所有队友,无视距离,再按恢复显示
3.按距离自动隐藏,默认距离500, 可以输入!hd 1000 来将距离提高至 1000 (范围 1 - 1999)

此插件有概率会导致服务器崩溃炸服 或许与 Transmit的不稳定性有关 不建议使用
```
---

```
Hide nearby teammates with three different modes.
Open the menu with !hide.
SQLite database supported.

Supports SQLite database to save player settings.
After a player joins the server, a personal table is automatically created
based on the SteamID and filled with default settings.

1. Global Hide  
   When enabled, hides all teammates regardless of distance.

2. Right-Click Toggle Hide  
   When enabled, press right-click once to hide all teammates
   regardless of distance.  
   Press right-click again to restore visibility.

3. Distance-Based Auto Hide  
   Automatically hides teammates within a certain distance.  
   Default distance: 500  
   You can use `!hd 1000` to increase the distance to 1000  
   (Range: 1 – 1999)

Warning  
This plugin has a chance to cause server crashes.
It may be related to instability in entity transmit.
Use is **NOT recommended** on production servers.
```
